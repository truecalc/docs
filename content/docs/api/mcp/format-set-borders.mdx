| Name | Type | Required | Description |

| `sheet` | `string` | yes | The sheet name. |
| `range` | `{ from: string; to: string }` | yes | The target range, e.g. `{"from": "A1", "to": "B3"}`. May legitimately arrive "backwards", `from` below/right of `to`, normalized before use. |
| `mode` | `"all", "inner", "horizontal", "vertical", "outer", "left", "top", "right", "bottom", "clear"` | yes | Which edges to target. |
