## Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `sheet` | `string` | yes | — |
| `range` | `{ from: string; to: string }` | yes | The filter's own range, its FIRST row is the un-hideable header row. Must span more than one row, a single-row range has no body rows to filter. |
| `criteria` | `array of { column: string; values: array of string }` | no | Per-column checked-value lists to apply right after creating the filter. A column omitted here starts unfiltered. Defaults to `[]`. |

| --- | --- | --- | --- |
